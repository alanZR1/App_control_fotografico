# Control Fotográfico de Obras - Aplicación móvil

Aplicación Flutter para registrar y consultar evidencia fotográfica de obras. El proyecto se encuentra en construcción y actualmente funciona con datos simulados; todavía no consume el backend.

La documentación técnica para transferencia y seguimiento está en [`docs/DOCUMENTACION_TECNICA.md`](docs/DOCUMENTACION_TECNICA.md).

## Ejecución rápida

Requisitos: Flutter, Android Studio y un emulador o dispositivo Android.

```bash
flutter pub get
flutter run
```
